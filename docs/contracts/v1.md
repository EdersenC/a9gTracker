# Drone Toolkit Contract Spec v1

Status: frozen for `v1.0.x` implementation lanes.

## Scope

This document defines source-of-truth contracts for:
- `VehiclePortV1`
- `TelemetryFrameV1`
- `MissionPlanV1`
- `FailsafeEventV1`
- `MissionRuntimeAPI`

It also defines integration-facing contracts for:
- `PX4SITLScenarioContractV1`
- `ToolkitCLIContractV1`

## Compatibility Rules (`v1.x`)

1. Existing required fields and method names are immutable.
2. New fields may be added only as optional/additive fields.
3. Enum values are append-only; no rename/remove in `v1.x`.
4. `MissionPlanValidationCodeV1` values are stable and must not change.
5. `VehicleCommandErrorCodeV1` values are stable and must not change.
6. Behavioral tightening is allowed only when it does not change schema shape.

## VehiclePortV1

Consumer tags: Adapter agent (implements), Runtime agent (consumes), SITL agent (fixture adapter).

Async methods:
- `connect()`
- `arm()`
- `set_mode(mode)`
- `upload_mission(plan)`
- `start_mission()`
- `goto_home()`
- `hold()`
- `abort(reason)`
- `disconnect()`

Telemetry:
- `telemetry.subscribe(callback)` emits `TelemetryFrameV1`.

Errors:
- Commands raise `VehicleCommandErrorV1` with `VehicleCommandErrorCodeV1`.

## TelemetryFrameV1

Consumer tags: Runtime agent, SDK/CLI agent, SITL agent.

Required fields:
- `monotonic_ts_ms`: monotonic timestamp in milliseconds.
- `wall_ts_iso8601`: wall-clock timestamp for logs and traces.
- `position`: `{lat, lon, alt_m}`.
- `velocity_mps`
- `heading_deg` in `[0, 360)`.
- `battery_pct` in `[0, 100]`.
- `gps_fix`: normalized enum.
- `link_state`: `UP | DEGRADED | LOST`.
- `flight_mode`: normalized mode string.
- `armed`: boolean.
- `mission_progress`: `{current_wp, total_wp}`.
- `health_flags`: set of normalized health flag strings.

Forward compatibility:
- `optional_fields` may include additive adapter/runtime metadata.

## MissionPlanV1

Consumer tags: SDK/CLI agent (author/validate), Runtime agent (execute), Adapter agent (upload translation).

Required fields:
- `mission_id`
- `home_position`
- `waypoints[]`
- `rth_policy`
- `cruise_speed_mps`
- `altitude_policy`
- `timeout_policy`

Optional field:
- `geofence` (polygon or cylinder)

Validation behavior:
- Validation is strict and deterministic.
- On invalid plan, constructor raises `MissionPlanValidationExceptionV1`.
- Exception includes complete error list with stable codes:
  - `MISSION_ID_REQUIRED`
  - `HOME_POSITION_REQUIRED`
  - `WAYPOINTS_REQUIRED`
  - `WAYPOINT_ALTITUDE_INVALID`
  - `WAYPOINT_LAT_LON_INVALID`
  - `CRUISE_SPEED_INVALID`
  - `GEOFENCE_INVALID`
  - `TIMEOUT_INVALID`

Immutability rule:
- `MissionPlanV1` is frozen and treated as immutable after creation.

## FailsafeEventV1

Consumer tags: Runtime agent (policy), SDK/CLI agent (display), SITL agent (assertions).

Event taxonomy:
- `GEOFENCE_BREACH`
- `LINK_LOSS`
- `LOW_BATTERY`
- `MISSION_ABORT`
- `VEHICLE_ERROR`

Payload:
- `event_type`
- `severity`: `INFO | WARNING | CRITICAL`
- `source`: `RUNTIME | VEHICLE | OPERATOR | SYSTEM`
- `monotonic_ts_ms`
- `reason`
- `details` (optional key/value map)

Default policy mapping (`DEFAULT_FAILSAFE_ACTIONS_V1`):
- `GEOFENCE_BREACH -> RTH`
- `LINK_LOSS -> HOLD`
- `LOW_BATTERY -> RTH`
- `MISSION_ABORT -> ABORT`
- `VEHICLE_ERROR -> ABORT`

Runtime may override mapping with explicit configuration, but event taxonomy/payload stays stable.

## MissionRuntimeAPI

Consumer tags: Runtime agent (implements), SDK/CLI agent (control plane), SITL agent (scenario assertions).

States:
- `IDLE`
- `PRECHECK`
- `ARMED`
- `ENROUTE`
- `RTH`
- `HOLD`
- `COMPLETED`
- `ABORTED`
- `FAILED`

API:
- runtime is bound to `VehiclePortV1` at initialization.
- `start(plan)`
- `stop()`
- `abort(reason)`
- `get_state()`
- `event_stream()` yields runtime events including failsafe transitions.

## PX4SITLScenarioContractV1

Consumer tags: SITL integration/CI agent.

Contract requirements:
- Boot PX4 SITL deterministically.
- Load mission fixture via `MissionPlanV1`.
- Capture telemetry and runtime events (`TelemetryFrameV1`, `RuntimeEventV1`, `FailsafeEventV1`).
- Assert expected runtime state transitions for scenarios:
  - nominal mission
  - geofence breach
  - link loss
  - low battery
  - operator abort
- Emit deterministic artifacts:
  - JUnit XML
  - JSON trace with state/event timeline

## ToolkitCLIContractV1

Consumer tags: SDK/CLI agent, SITL integration agent.

Commands:
- `mission validate`
- `mission run --sitl`
- `mission abort`
- `telemetry tail`

Exit codes:
- `0`: success
- `2`: validation error
- `3`: runtime failure
- `4`: safety-triggered abort

## Canonical examples

Telemetry example:

```python
TelemetryFrameV1(
    monotonic_ts_ms=123456,
    wall_ts_iso8601="2026-05-13T15:01:22Z",
    position=PositionV1(lat=37.42, lon=-122.08, alt_m=42.0),
    velocity_mps=8.5,
    heading_deg=91.0,
    battery_pct=87.5,
    gps_fix=GPSFixV1.FIX_3D,
    link_state=LinkStateV1.UP,
    flight_mode="MISSION",
    armed=True,
    mission_progress=MissionProgressV1(current_wp=1, total_wp=5),
    health_flags=frozenset({"EKF_OK"}),
)
```

Mission example:

```python
MissionPlanV1(
    mission_id="mission-alpha",
    home_position=GeoPointV1(lat=37.42, lon=-122.08, alt_m=10.0),
    waypoints=(
        WaypointV1(position=GeoPointV1(lat=37.421, lon=-122.081, alt_m=40.0)),
        WaypointV1(position=GeoPointV1(lat=37.422, lon=-122.082, alt_m=40.0)),
    ),
    geofence=GeofenceV1(
        geofence_type=GeofenceTypeV1.CYLINDER,
        center=GeoPointV1(lat=37.42, lon=-122.08, alt_m=10.0),
        radius_m=500.0,
        min_alt_m=10.0,
        max_alt_m=120.0,
    ),
    rth_policy=RTHPolicyV1(low_battery_threshold_pct=20.0, return_altitude_m=60.0),
    cruise_speed_mps=10.0,
    altitude_policy=AltitudePolicyV1(min_alt_m=20.0, max_alt_m=120.0),
    timeout_policy=TimeoutPolicyV1(precheck_timeout_s=30.0, mission_timeout_s=900.0, command_timeout_s=5.0),
)
```
